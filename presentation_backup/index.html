Technical walkthrough

Implementation Map

Use this if the live app is unavailable and you still need to explain how the visible behavior maps to code.

1. Agent Loop

defence_agent/agent.py and defence_agent/tools.py let the runtime call search_documents once or multiple times for a planning task.

2. Retrieval

defence_agent/retrieval/chroma_index.py embeds the query, applies metadata filters, searches Chroma, and sends candidates to Cohere Rerank.

3. Authorization

Persona access is applied before evidence is sent to generation. Restricted source text is not used for unauthorized answers.

4. Grounded Answer

defence_agent/grounding.py sends selected documents to Cohere Chat and reads native citation spans back into the audit object.

5. Trace

defence_agent/session.py and the UI view model turn tool calls, retrieval audits, sources, exclusions, and citations into the trace shown above.

6. Evaluation

defence_agent/data/evals/demo_query_registry.yaml and the eval reports check expected sources, refusals, citation resolution, and search behavior.
